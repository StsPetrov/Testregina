# 1001Ranobe.ru — Социальная платформа для чтения и прослушивания ранобэ

## О проекте

1001Ranobe.ru — это не просто библиотека книг, а **целая экосистема** вокруг азиатских новелл. Сайт объединяет чтение, прослушивание, социальное взаимодействие и монетизацию в одном интерфейсе.

**Стек:** WordPress (PHP 8.2) + Audiobookshelf (Docker) + HTML5 Audio + Telegram Bot API
**Хостинг:** Timeweb (логин magsport)
**Аудиосервер:** https://audiobook.1001ranobe.ru

## Концепция

Пользователь заходит на сайт с тёмной темой. На главной — персональная статистика (прочитано книг, прослушано часов, ранг). Ниже — книги с прогресс-барами, избранное, новинки.

**Аудиокнига:** профессиональный плеер с запоминанием позиции, скоростью, перемоткой. Рядом — вкладка «Читать» с синхронизацией на ту же главу.

**Текстовая книга:** читалка с настройками шрифта, ширины, дневным/ночным режимом. Прогресс сохраняется автоматически.

**Автор/переводчик:** загружает книгу, система разбирает на главы, подтягивает метаданные. Видит статистику, доход от рекламы. Получает 70%.

**Фанат:** вступает в группы, обсуждает с друзьями, получает достижения («Прочитал 1000 глав», «Слушал 500 часов»).

**Покупатель:** заказывает профессиональную озвучку книги (0.1₽/глава, от 50₽), покупает мерч.

## Ключевые цифры

- **783 книги** в библиотеке
- **576 000 глав** (в среднем 736 глав на книгу)
- **288 аудиотреков** в крупнейшей аудиокниге
- **13.4 ГБ** база данных
- **50+ активных читателей** в день

## Функционал

### Чтение
- Читалка с настройками (шрифт, междустрочный, ширина, ночной режим)
- Сохранение прогресса чтения
- Навигация по главам с поиском
- Кнопка «Продолжить чтение» на странице книги
- Промотка списка глав к последней читаемой

### Аудио
- HTML5 Audio плеер (без Howler.js)
- Плейлист с длительностями треков
- Сохранение позиции каждые 5 секунд
- Восстановление позиции при возврате
- Кнопки iOS (промотка ±10с, MediaSession)
- Скролл плейлиста к активному треку
- Регулировка скорости (1x, 1.25x, 1.5x, 2x)

### Парсинг
- Парсер ifreedom.su v2 с пакетной загрузкой глав
- Админка с фильтрами, сортировкой, выбором книг
- Логи в админке и Telegram
- Крон с защитой от зацикливания
- Пакетная обработка книг (чанки по 3)

### Монетизация
- Донаты через CloudTips
- Заказ озвучки через T‑Bank (кнопка с расчётом стоимости)
- Кнопка «Поддержать проект» в читалке и на странице книги

### Социальное (в планах)
- Профили пользователей, друзья, группы
- Геймификация (достижения, рейтинг)
- Личные сообщения, стена активности

## Преимущества

- **Глубокая интеграция аудио и текста** — единый плеер и читалка с синхронизацией
- **Автоматический парсинг** — библиотека пополняется сама
- **Удобная читалка** — настройки под пользователя
- **Профессиональная озвучка** — возможность заказать любую книгу
- **Пакетная обработка** — парсер не падает на больших книгах
- **Telegram-оповещения** — администратор видит всё в реальном времени

## Недостатки (что нужно доделать)

- **Callback T‑Bank** — заказ создаётся до оплаты, а не после
- **Размер БД** — 13.4 ГБ, нужно сжатие или архивирование
- **Плеер** — нет автовосстановления позиции без клика
- **Крон** — не работает на тарифе Timeweb (лимит обращений к БД)
- **Мобильная версия** — базовая, требует доработки
- **Социальная сеть** — только в планах
- **Git** — не настроен (отключён после конфликтов)

## Перспективы

- **Рынок ранобэ в России растёт взрывными темпами** — тысячи людей читают китайские, корейские, японские новеллы
- **Ниша уникальна** — нет конкурентов с таким же функционалом
- **Монетизация** — множественные источники дохода (донаты, озвучка, мерч, реклама, партнёрки)
- **Социальная сеть** — удержание аудитории через сообщество
- **Мобильное PWA** — офлайн-доступ к книгам
- **ИИ-саммаризация** — краткие содержания глав через LLM

## Правила работы с кодом (для ИИ-ассистента)

- Никакого git на сервере. Работаем напрямую с файлами.
- Пользователь даёт файл или кусок кода → ассистент даёт правку в формате «найти → заменить».
- Перед любой правкой — копия файла (cp file.php file.php.bak).
- Команды: только nano, cp, grep, tail. Никаких rm, find, xargs.
- Одно изменение за раз. Сломалось — стоп, разбираемся.
- WP_DEBUG включён для логов.
- Всегда проверять работу на iOS (Safari).
- После каждого крупного изменения проверять: плеер, читалку, парсер, каталог, админку.
