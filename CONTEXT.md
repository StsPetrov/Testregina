# 1001Ranobe.ru — Полный контекст проекта (объединённый)

## Идея и концепция

1001Ranobe.ru — это не просто сайт с книгами, а **социальная платформа-экосистема** вокруг азиатских новелл (ранобэ). Проект объединяет чтение, прослушивание, социальное взаимодействие и монетизацию в одном интерфейсе.

**Видение:** Пользователь заходит на сайт с тёмной темой. Видит персональную статистику (прочитано книг, прослушано часов, ранг). Ниже — книги с прогресс-барами, избранное, новинки. Открывает аудиокнигу — профессиональная озвучка, плеер запоминает позицию, можно переключить скорость. Рядом — вкладка «Читать» с синхронизацией на ту же главу. Читалка подстраивается под пользователя (шрифт, ширина, ночной режим). Автор загружает книгу — система сама разбирает на главы, подтягивает метаданные. Читатели общаются в группах, получают достижения, поддерживают авторов донатами.

**Ключевое преимущество:** Никто в России не делает такую экосистему для ранобэ. Конкуренты — просто библиотеки с устаревшим дизайном.

## Технологический стек

- **Backend:** WordPress (PHP 8.2) с глубокой кастомизацией. Тема `audio-podcast` (своя).
- **Хостинг:** Timeweb (виртуальный хостинг, логин `magsport`).
- **Домашний сервер:** Windows, Docker.
  - **MinIO:** S3-совместимое хранилище. Бакеты: `1001ranobe-chapters` (тексты глав), `1001ranobe-audio` (аудиокниги), `ads` (реклама). Доступ по HTTPS через `audiobook.1001ranobe.ru:9000`.
  - **Audiobookshelf (ABS):** Легаси, пока хранит старые аудиокниги. Планируется удалить после полного перехода на MinIO.
  - **Nginx:** Прокси для ABS и MinIO (SSL-терминация).
  - **mc (MinIO Client):** Консольное управление политиками бакетов.
  - **Cyberduck:** GUI для ручной загрузки аудиокниг в MinIO.
  - **Ollama + Mistral 7B (в планах):** ИИ для обработки текста.
- **База данных:** MySQL (Timeweb). **Критически важно:** лимит 7000 обращений в сутки. Парсеры и кроны не должны превышать этот лимит.
- **Парсеры:** Собственные на PHP.
  - `abs-ifreedom-v2.php` — ядро парсера ifreedom.su.
  - `abs-parser-ranobe-fb2.php` — ядро парсера FB2 (ranobe.me).
  - `abs-ifreedom-v2-admin.php` — админка парсера и страница миграции в MinIO.
  - `abs-ifreedom-v2-cron.php` — крон для автоматического парсинга.
- **Плеер:** `abs-player-native.js` — HTML5 Audio (без Howler.js). Стримит аудио из MinIO.
- **Оповещения:** Telegram-бот `@otrsnobeBot` (токен и chat_id в коде).
- **Платежи:** CloudTips (донаты), T‑Bank (заказ озвучки).
- **SEO:** Yoast SEO + собственные доработки (schema.org, авто-title, авто-description).
- **Git:** Не используется на сервере. GitHub только для документации и бэкапа темы.

## Идеология и принципы работы

- **Никакого git на сервере.** Работаем напрямую с файлами.
- **Формат правок:** «найти → заменить». Перед правкой — копия файла.
- **Одно изменение за раз.** Сломалось — стоп, разбираемся.
- **Бэкап перед каждой сессией.**
- **Минимум зависимостей:** свой плеер, свои парсеры, своё хранилище.
- **Экономия ресурсов:** Mistral 7B q4 на CPU (8 ГБ RAM), MinIO на домашнем сервере, БД без текстов глав.
- **GitHub только для задач (Issues) и контекста (CHECKLIST.md, CONTEXT.md).**
- **Файлы скидываются или куски кода по необходимости.**
